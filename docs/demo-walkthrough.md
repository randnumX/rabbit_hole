# RabbitHole Demo Walkthrough

## Setup
1. Start the backend with `uvicorn app.main:app --reload` from `apps/backend`.
2. Run `pnpm dev:extension` from the repo root.
3. Load `apps/extension/dist` as an unpacked extension in Chrome.

## Live Demo Script
1. Open a ChatGPT conversation about building an LLM browser extension.
2. Open the RabbitHole launcher in the top-right corner.
3. Click `Analyze`.
4. Call out the root topic in the summary card and the rabbit sitting on the current turn.
5. Walk down the main trail and show how deepening stays centered.
6. Point to the lighter side branch for accessibility or another still-related detour.
7. Highlight the broken rabbit-hole node where the conversation sharply pivots.
8. Select the return node and explain how root relevance recovered.
9. Click a node and show the transcript scrolling to the corresponding ChatGPT message.

## Seeded Demo Story
- Root topic: building a ChatGPT browser extension that visualizes topic drift.
- Side quest: accessibility and keyboard navigation for the sidebar.
- Rabbit hole: a sudden regex capture groups detour.
- Return: resuming the extension transcript-scroll implementation.

## What To Emphasize
- This is a storytelling layer, not an analytics dashboard.
- The hero answer is "where did the conversation go off track?"
- Each node can explain itself with root relevance, local coherence, and a short natural-language rationale.
